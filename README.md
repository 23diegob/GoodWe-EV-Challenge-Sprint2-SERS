# GoodWe-EV-Challenge-Sprint2-SERS
# EcoCharge Smart Grid - Sprint 2

## Descrição do Projeto
O EcoCharge Smart Grid é uma solução voltada para mobilidade elétrica inteligente, gestão energética e infraestrutura sustentável.

## Objetivo da Sprint
Desenvolver uma prova de conceito funcional que demonstre a viabilidade técnica da solução proposta na Sprint 1.

## Funcionalidade Demonstrada
O protótipo simula um sistema inteligente de carregamento que monitora o nível de bateria dos veículos e distribui energia de forma eficiente, priorizando o carro com menor carga ou maior urgência.

## Arquitetura do Sistema
- Entrada de dados: nível de bateria dos veículos, demanda energética e geração solar simulada.
- Processamento: lógica de decisão para priorização de carregamento.
- Saída: indicação do veículo priorizado e dados de energia distribuída.

## Sustentabilidade e Energias Renováveis
A solução considera o uso de energia solar como fonte renovável e busca otimizar o consumo energético, reduzindo desperdícios e melhorando a eficiência do carregamento.

## Instruções de Uso
1. Executar o programa/simulação.
2. Inserir ou visualizar os dados dos veículos.
3. Observar qual veículo recebe prioridade no carregamento.
4. Analisar os dados exibidos pelo sistema.
